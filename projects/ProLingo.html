Learning platform

ProLingo

An English learning platform built with Flet and SQLite. Users take multimedia quizzes and follow course pages; admins manage users and questions from a dashboard.

Flet Python SQLite3 Reportlab

Key features

  • User registration and login
  • Levels from Elementary to Advanced
  • Quizzes with text, image, and audio
  • Change answers before moving to the next question
  • Results table with PDF export
  • Admin panel for users and questions
  • Course pages: Grammar, Vocabulary, Speaking, Listening, Exercises

User panel

  • Session-based login
  • View personal performance stats
  • Edit password, level, and username
  • Access learning materials and quizzes
  • Download quiz results as PDF

Admin panel

  • View registered users and performance stats
  • Add questions manually or import from JSON/Excel
  • Upload question assets (images/audio)
  • Add new users and admins
