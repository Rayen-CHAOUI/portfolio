Mobile app

Car Maintenance

Flutter mobile app for tracking vehicle servicing, dates, costs, and mileage.

Flutter / Dart SQLite

Features

  • Add one or more vehicles (make, model, year)
  • View all registered vehicles
  • Display maintenance records per vehicle
  • Add a service with type, description, dates, price, and mileage

User experience

  • On first launch, select an existing vehicle or create a new one
  • See the selected vehicle’s maintenance list
  • Quick add via a floating action button
