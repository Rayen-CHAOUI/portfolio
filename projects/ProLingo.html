ProLingo

Project Overview

ProLingo An English language platform built with Flet and SQLite3. Where users can register, log in, and take quizzes with multimedia questions (text, image, and audio). Admins can manage users and questions via a Dashboard, Users also have access to various learning course pages such as Grammar, Vocabulary, Speaking, Listening, and Exercises.

Key Features

  • User registration and login system (with ID and password)
  • Multiple difficulty levels: Elementary, Pre-intermediate, Intermediate, Upper-intermediate, Advanced
  • Interactive quiz interface with audio and image support
  • Ability to change answers before clicking “Next”
  • Result page with detailed table of correct/wrong answers
  • Ability to extract results into PDF files.
  • Admin panel for managing users and quiz questions
  • Profile page to edit user's info.
  • Learning course pages: Grammar, Vocabulary, Speaking, Listening, Exercises

User Panel

  • stored in `backend/eplanet_users.db/user`
  • User login via session.
  • View own performance stats.
  • Edit own info (password, level, username).
  • Access learning materials and quizzes.
  • Upload question assets (images/audio).
  • Download quiz results as PDF.
  • Access to various learning course pages.
  • Quiz questions with text, image, and audio formats.
  • Interactive quiz interface with real-time feedback.
  • Ability to change answers before submitting.
  • Result page with detailed statistics.

Admin Panel

  • stored in `backend/eplanet_users.db/admin`
  • Admin login via session.
  • View registered users with performance stats.
  • Add questions manually or import from JSON/Excel.
  • Upload question assets (images/audio).
  • Edit user's info (password, level, username).
  • Add new users and admins.

Technologies Used

  • Frontend & UI : Flet framework (Flutter-like UI in Python)
  • Backend : Python, SQLite3
  • Assets : Local image/audio files for questions
  • SQLite : for user data and quiz questions
  • Reportlab : PDF export

Project Structure

  • backend/: Authentication and database logic
  • frontend/: (user/ ), (admin/ ) : All UI views (login, signup, dashboard, quiz, results, add_question)
  • assets/: Image and audio folders for quiz media
